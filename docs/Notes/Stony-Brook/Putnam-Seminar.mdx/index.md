The Stony Brook [Putnam Seminar](https://www.math.stonybrook.edu/~rdhough/putnam_seminar/2026/2026.html) is a weekly seminar run by Professor [Robert Hough](https://www.math.stonybrook.edu/~rdhough/) for the purpose of [Putnam Competition](https://www.math.stonybrook.edu/~rdhough/putnam_seminar/2026/2026.html) preperation and free pizza.
