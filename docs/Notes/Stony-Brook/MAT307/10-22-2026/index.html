Lagrange Multipliers​

Last time, we introduced Lagrange multipliers, which say:

If we want to find the local minimum or local maximum of an objective function fff subject to a constraint g=kg=kg=k (with ∇g≠0\nabla g\ne 0∇g=0 on the constraint set), then:

p is a local min or local max  ⟹  ∇f(p)=λ∇g(p)p \text{ is a local min or local max}\implies \nabla f(p)=\lambda \nabla g(p)p is a local min or local max⟹∇f(p)=λ∇g(p)

This time, we will focus on their applications.

Application of Lagrange Multipliers​

Example 1

DDD is the level set ℓ1\ell_1ℓ1​ of g(x,y)=x2+4y2g(x,y)=x^2+4y^2g(x,y)=x2+4y2. For any point p=(x,y)∈Dp=(x,y)\in Dp=(x,y)∈D, there is a unique rectangle RpR_{p}Rp​, with sides parallel to the axes and a corner at ppp, with area:

f(x,y)=4xyf(x,y)=4xyf(x,y)=4xy

Then, we transform the problem into finding the maximum of fff over DDD. By Lagrange multipliers:

p=(x,y) is a local min or local max  ⟹  ∇f(p)=λ∇g(p) for some λp=(x,y)\text{ is a local min or local max}\implies \nabla f(p) =\lambda \nabla g(p) \text{ for some }\lambdap=(x,y) is a local min or local max⟹∇f(p)=λ∇g(p) for some λ

Given f(x,y)=4xyf(x,y)=4xyf(x,y)=4xy, g(x,y)=x2+4y2g(x,y)=x^2+4y^2g(x,y)=x2+4y2, and D={(x,y)∈R2 such that x2+4y2=1}D=\{ (x,y)\in \mathbb{R}^2\text{ such that } x^2+4y^2=1 \}D={(x,y)∈R2 such that x2+4y2=1}:

∇f(x,y)=(4y,4x)∇g(x,y)=(2x,8y)\nabla f(x,y)=(4y,4x) \qquad \nabla g(x,y)= (2x,8y)∇f(x,y)=(4y,4x)∇g(x,y)=(2x,8y)

{4y=λ2x4x=λ8yx2+4y2=1  ⟹  {0=y(λ2−1)x2+4y2=1\begin{cases} 4y=\lambda 2x\\ 4x=\lambda 8y\\ x^2+4y^2=1 \end{cases} \implies \begin{cases} 0=y(\lambda^2-1)\\ x^2+4y^2=1 \end{cases}⎩⎨⎧​4y=λ2x4x=λ8yx2+4y2=1​⟹{0=y(λ2−1)x2+4y2=1​

    Then x=±1x=\pm 1x=±1, and the rectangle is degenerate with area 000, so it is not the maximum.

Example 2

A parallelepiped inscribed in a sphere must be a rectangular box. No matter which box we take, we can rotate it so that its edges are parallel to the xxx-, yyy-, and zzz-axes. If (x,y,z)(x,y,z)(x,y,z) with x,y,z>0x,y,z>0x,y,z>0 is the corner in the first octant, the volume is:

Vector Fields​

Vector Field

A Vector Field is a function f:Rn→Rnf: \mathbb{R}^n\rightarrow \mathbb{R}^nf:Rn→Rn, which assigns a vector to every point. For example, f(x,y)=(−y,x)f(x,y)=(-y,x)f(x,y)=(−y,x) in R2\mathbb{R}^2R2:

Given a scalar function g:Rn→Rg:\mathbb{R}^n\rightarrow \mathbb{R}g:Rn→R, there is a canonical way to associate a vector field to ggg, namely through the gradient ∇g\nabla g∇g.
