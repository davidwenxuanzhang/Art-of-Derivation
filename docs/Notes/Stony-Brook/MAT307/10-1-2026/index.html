Taylor Approximation and Min/Max​

Here, we are discussing:

  • Local min/max of functions of several variables
  • Local behavior of such functions

1-D Calculus Review​

1-d Calculus Optimization

Recall from 1-d calculus:

R→R\mathbb{R}\rightarrow \mathbb{R}R→R
  • If fff has a local min/max at x0x_0x0​, then f′(x0)=0f^{\prime}(x_0)=0 f′(x0​)=0
  • If f′(x0)=0f^{\prime}(x_0)=0f′(x0​)=0, then there is a second derivative test to check whether x0x_0x0​ is a local min or local max.
    • f′′(x0)>0  ⟹  x0f^{\prime\prime} (x_0)>0 \implies x_0f′′(x0​)>0⟹x0​ is a local min, and fff is convex (concave up) there
    • f′′(x0)<0  ⟹  x0f^{\prime\prime} (x_0)<0 \implies x_0f′′(x0​)<0⟹x0​ is a local max, and fff is concave (concave down) there

We want to generalize this picture!

Taylor Approximation in 1-D Calculus

For a function f:R→Rf:\mathbb{R}\rightarrow \mathbb{R}f:R→R

Tf(n)(x0+ε)=f(x0)+εf′(x0)+ε22f′′(x0)+⋯+εnn!f(n)(x0)T_{f}^{(n)}(x_0+\varepsilon)= f(x_0)+\varepsilon f^{\prime}(x_0)+\frac{\varepsilon^2}{2}f^{\prime\prime}(x_0)+\cdots +\frac{\varepsilon^n}{n!}f^{(n)}(x_0) Tf(n)​(x0​+ε)=f(x0​)+εf′(x0​)+2ε2​f′′(x0​)+⋯+n!εn​f(n)(x0​)

More importantly, if fff is (n+1)(n+1)(n+1) times differentiable, that is, f(n+1)f^{(n+1)}f(n+1) exists and is continuous, then the following theorem holds:

∣f(x0+ε)−Tf(n)(x0+ε)∣≤Cεn+1\left|f(x_0+\varepsilon)-T_{f}^{(n)}(x_0+\varepsilon) \right|\le C\varepsilon^{n+1}​f(x0​+ε)−Tf(n)​(x0​+ε)​≤Cεn+1

Relation to Second Derivative Test

This immediately implies the second derivative test:

f(x0+ε)≈f(x0)+εf′(x0)+ε22f′′(x0)f(x_0+\varepsilon)\approx f(x_0)+\varepsilon f^{\prime}(x_0)+\frac{\varepsilon^2}{2}f^{\prime\prime}(x_0)f(x0​+ε)≈f(x0​)+εf′(x0​)+2ε2​f′′(x0​)
  • If f′(x0)=0f^{\prime}(x_0)=0f′(x0​)=0, then f(x0+ε)≈f(x0)+ε22f′′(x0)f(x_0+\varepsilon)\approx f(x_0)+\frac{\varepsilon^2}{2}f^{\prime\prime}(x_0)f(x0​+ε)≈f(x0​)+2ε2​f′′(x0​) for ε\varepsilon ε small enough
    • f(x0+ε)>f(x0)f(x_0+\varepsilon)> f(x_0)f(x0​+ε)>f(x0​) if f′′(x0)>0f^{\prime\prime}(x_0)>0 f′′(x0​)>0   ⟹  x0\implies x_0⟹x0​ is a local min
    • f(x0+ε)<f(x0)f(x_0+\varepsilon)< f(x_0)f(x0​+ε)<f(x0​) if f′′(x0)<0f^{\prime\prime}(x_0)<0 f′′(x0​)<0   ⟹  x0\implies x_0⟹x0​ is a local max

Gradient Test​

Gradient Test

Recall from last time that given a vector v=(x,y)\mathbf{v}=(x,y)v=(x,y), the tangent plane is:

(v,f(v))+t1(1,0,∂xf(v))+t2(0,1,∂yf(v)) \big(\mathbf{v},f(\mathbf{v}) \big)+t_1\big(1,0,\partial_{x}f(\mathbf{v})\big)+t_2\big(0,1,\partial_{y}f(\mathbf{v})\big)(v,f(v))+t1​(1,0,∂x​f(v))+t2​(0,1,∂y​f(v))

If v\mathbf{v}v is a local min or local max, we should expect that the tangent plane is parallel to the x,yx,yx,y plane:

  ⟹  ∂xf(v)=∂yf(v)  ⟺  ∇f(v)=0\implies \partial_{x}f(\mathbf{v})=\partial_{y}f(\mathbf{v})\iff \nabla f(\mathbf{v})=0⟹∂x​f(v)=∂y​f(v)⟺∇f(v)=0
Proposition

If v\mathbf{v}v is a local min or local max for fff, then ∇f(v)=0\nabla f(\mathbf{v})=0∇f(v)=0

Derivation

  • Proof 1

    When we do a local computation, we can always use a Taylor expansion instead of ttt

    f(v+ε)≈f(v)+∇f(v)⋅εf(\mathbf{v}+\mathbf{\varepsilon})\approx f(\mathbf{v})+\nabla{f}(\mathbf{v})\cdot \varepsilonf(v+ε)≈f(v)+∇f(v)⋅ε

    If we want to prove "v is a local min or local max   ⟹  ∇f(v)=0\mathbf{v}\text{ is a local min or local max } \implies \nabla f(\mathbf{v})=0 v is a local min or local max ⟹∇f(v)=0", we may prove the contrapositive that:

    ∇f(v)≠0  ⟹  v is neither a local min nor a local max \nabla f(\mathbf{v})\ne 0\implies \mathbf{v}\text{ is neither a local min nor a local max } ∇f(v)=0⟹v is neither a local min nor a local max 

    I can take ε\varepsilonε in the ∇f(v)\nabla f(\mathbf{v})∇f(v) direction:

    ε=ε′∇f(v)\mathbf{\varepsilon}=\varepsilon^{\prime}\nabla f(\mathbf{v})ε=ε′∇f(v)

    Plug in back to the Taylor expansion form

    f(v+ε)≈f(v)+∇f(v)⋅ε=f(v)+∇f(v)⋅ε′∇f(v)=f(v)+ε′(∇f(v)⋅∇f(v))=f(v)+ε′∥∇f(v)∥2\begin{align*} f(\mathbf{v}+\mathbf{\varepsilon})&\approx f(\mathbf{v})+\nabla f(\mathbf{v})\cdot \mathbf{\varepsilon} \\ &=f(\mathbf{v})+\nabla f(\mathbf{v})\cdot \varepsilon^{\prime}\nabla f(\mathbf{v})\\ &=f(\mathbf{v})+\varepsilon^{\prime}\big( \nabla f(\mathbf{v})\cdot\nabla f(\mathbf{v})\big)\\ &=f(\mathbf{v})+\varepsilon^{\prime}\left\|\nabla f(\mathbf{v}) \right\|^2 \end{align*}f(v+ε)​≈f(v)+∇f(v)⋅ε=f(v)+∇f(v)⋅ε′∇f(v)=f(v)+ε′(∇f(v)⋅∇f(v))=f(v)+ε′∥∇f(v)∥2​
    • If ε′>0\varepsilon^{\prime} >0 ε′>0, then f(v+ε)>f(v)f(\mathbf{v}+\mathbf{\varepsilon}) > f(\mathbf{v}) f(v+ε)>f(v)
    • If ε′<0\varepsilon^{\prime} < 0 ε′<0, then f(v+ε)<f(v)f(\mathbf{v}+\mathbf{\varepsilon}) < f(\mathbf{v}) f(v+ε)<f(v)

    Therefore, with proof by contrapositive, if v\mathbf{v}v is a local min or local max for fff, then ∇f(v)=0\nabla f(\mathbf{v})=0∇f(v)=0 ■\blacksquare■

  • Proof 2

    I want to take a vertical slice along the ∇f\nabla f∇f direction, and the vertical slice could be written as:

    g(t)=f(v+t∇f(v))g(t)=f(\mathbf{v}+t\nabla f(\mathbf{v}))g(t)=f(v+t∇f(v))

    If v\mathbf{v} v is a local min/max for fff, then it is also a local min/max for ggg at t=0t=0t=0

    g′(t)=∇f(v+t∇f(v))⋅∇f(v)g^{\prime}(t)=\nabla f\big(\mathbf{v}+t\nabla f(\mathbf{v}) \big)\cdot \nabla f(\mathbf{v})g′(t)=∇f(v+t∇f(v))⋅∇f(v)

    At t=0t=0t=0:

    g′(0)=∇f(v)⋅∇f(v)=∥∇f(v)∥2\begin{align*} g^{\prime}(0)&=\nabla f(\mathbf{v})\cdot \nabla f(\mathbf{v})\\ &=\| \nabla f(\mathbf{v})\|^2 \end{align*}g′(0)​=∇f(v)⋅∇f(v)=∥∇f(v)∥2​

    As we know g′(0)=0g^{\prime}(0)=0g′(0)=0, thus:

    ∥∇f(v)∥2=0\| \nabla f(\mathbf{v})\|^2=0∥∇f(v)∥2=0

    Therefore:

    ∇f(v)=0■\nabla f(\mathbf{v})=0 \tag*{$\blacksquare$}∇f(v)=0■
Corollary

For a function f:D→Rf:D\rightarrow \mathbb{R}f:D→R, the condition ∇f(v)=0\nabla f(\mathbf{v})=0 ∇f(v)=0 could be used to find all possible candidates for local min/max.

Remark

If the domain has a boundary, we will need another criterion, that is to say, local min/max might exist where ∇f≠0\nabla f\ne 0∇f=0

Hessian Test​

From the previous part, if the gradient ∇f(v)=0\nabla f(\mathbf{v})=0∇f(v)=0, then v\mathbf{v}v is a candidate for local min/max, but how do I decide if v\mathbf{v}v is a local min or local max exactly?

Second-Order Taylor Approximation

Recall the Second-Order Taylor Approximation:

Tf(2)((x,y)+ε)=f(x,y)+∇f(x,y)⋅ε+12fxx(x,y)ε12+fxy(x,y)ε1ε2+12fyy(x,y)ε22\begin{align*} T_f^{(2)}((x,y)+\boldsymbol{\varepsilon}) &= f(x,y)+\nabla f(x,y)\cdot\boldsymbol{\varepsilon}\\ &\quad+\frac{1}{2}f_{xx}(x,y)\varepsilon_1^2\\ &\quad+f_{xy}(x,y)\varepsilon_1\varepsilon_2\\ &\quad+\frac{1}{2}f_{yy}(x,y)\varepsilon_2^2 \end{align*}Tf(2)​((x,y)+ε)​=f(x,y)+∇f(x,y)⋅ε+21​fxx​(x,y)ε12​+fxy​(x,y)ε1​ε2​+21​fyy​(x,y)ε22​​

In order to understand the sign of Tf(2)((x,y)+ε)T_f^{(2)}((x,y)+\boldsymbol{\varepsilon})Tf(2)​((x,y)+ε), we need to understand the sign of the last three lines, and the Hessian Test is a good tool.

Hessian Test

Hessian Test is the second derivative test for functions of several variables.

I can arrange the last three terms from the previous part into the matrix:

Hf(x,y)=[∂x2f(x,y)∂x∂yf(x,y)∂y∂xf(x,y)∂y2f(x,y)]H_f(x,y)= \begin{bmatrix} \partial_x^2 f(x,y) & \partial_x\partial_y f(x,y)\\ \partial_y\partial_x f(x,y) & \partial_y^2 f(x,y) \end{bmatrix}Hf​(x,y)=[∂x2​f(x,y)∂y​∂x​f(x,y)​∂x​∂y​f(x,y)∂y2​f(x,y)​]

Then, consider the following couple of quantities:

d1=∂x2f(x,y)d2=det⁡Hf(x,y)d_1=\partial_x^{2}f(x,y)\qquad d_2=\operatorname{det}{H_f(x,y)}d1​=∂x2​f(x,y)d2​=detHf​(x,y)

  • Case 1: d1d_1d1​, d2d_2d2​ are both positive
      ⟹  \implies ⟹ If ∇f(x,y)=0\nabla f(x,y)=0∇f(x,y)=0, then (x,y)(x,y)(x,y) is local min

  • Case 2: d1<0d_1<0d1​<0 and d2>0d_2>0d2​>0
      ⟹  \implies ⟹ If ∇f(x,y)=0\nabla f(x,y)=0∇f(x,y)=0, then (x,y)(x,y)(x,y) is local max

  • Case 3: d1>0d_1>0d1​>0 and d2<0d_2<0d2​<0 or d1d_1d1​, d2d_2d2​ are both negative
      ⟹  \implies ⟹ If ∇f(x,y)=0\nabla f(x,y)=0∇f(x,y)=0, then (x,y)(x,y)(x,y) is a saddle point (neither local min nor local max)

  • Case 4: d1=0d_1=0d1​=0 or d2=0d_2=0d2​=0
      ⟹  \implies ⟹ cannot decide
