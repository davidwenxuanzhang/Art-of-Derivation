Solving Linear Systems​

Goal

Recall from previous lecture that our Goal is to find a systematic way to solve a system of linear equations:

Ax=bA\mathbf{x}=\mathbf{b}Ax=b

that is to say, we want to find the vector x∈Rn\mathbf{x}\in\mathbb{R}^nx∈Rn such that:

{a11x1+⋯+a1nxn=b1,⋮am1x1+⋯+amnxn=bm.\begin{cases} a_{11}x_1+\cdots+a_{1n}x_n=b_1,\\ \qquad \vdots\\ a_{m1}x_1+\cdots+a_{mn}x_n=b_m. \end{cases}⎩⎨⎧​a11​x1​+⋯+a1n​xn​=b1​,⋮am1​x1​+⋯+amn​xn​=bm​.​
Example
{x1+3x2+x3=12x1+4x2+7x3=24x1+10x2+9x3=4  ⟹  A=[1312474109]b=[124]\begin{cases} x_1 + 3x_2 + x_3 = 1\\ 2x_1 + 4x_2 + 7x_3 = 2\\ 4x_1 + 10x_2 + 9x_3 = 4 \end{cases} \implies A= \begin{bmatrix} 1&3&1\\ 2&4&7\\ 4&10&9 \end{bmatrix} \quad \mathbf{b}= \begin{bmatrix} 1\\ 2\\ 4 \end{bmatrix}⎩⎨⎧​x1​+3x2​+x3​=12x1​+4x2​+7x3​=24x1​+10x2​+9x3​=4​⟹A=​124​3410​179​​b=​124​​

Observation

I can do all these operations at the level of (A∣b)(A\mid \mathbf{b})(A∣b) as a matrix; that is, I do not need to write down all those xix_ixi​s every time.

Operations

Below are some elementary operations that do not change the solution set of the matrix (A∣b)(A\mid \mathbf{b})(A∣b).

  • We can exchange two rows.
  • We can take a row and add a multiple of another row.
  • We can take a row and multiply it by a non-zero coefficient.

Echelon Form​

With those operations, any matrix can be reduced to the following form.

Echelon Form

The Echelon Form of a matrix looks like the following:

[0⋯01∗⋯∗∗⋯∗0⋯000⋯1∗⋯∗0⋯000⋯00⋯10⋯000⋯00⋯0]1:pivot∗:any number\begin{bmatrix} 0 & \cdots & 0 & \boxed{1} & * & \cdots & * & * & \cdots & * \\ 0 & \cdots & 0 & 0 & 0 & \cdots & \boxed{1} & * & \cdots & * \\ 0 & \cdots & 0 & 0 & 0 & \cdots & 0 & 0 & \cdots & \boxed{1} \\ 0 & \cdots & 0 & 0 & 0 & \cdots & 0 & 0 & \cdots & 0 \end{bmatrix} \quad \begin{aligned} \boxed{1}&: \text{pivot}\\ *&: \text{any number} \end{aligned}​0000​⋯⋯⋯⋯​0000​1​000​∗000​⋯⋯⋯⋯​∗1​00​∗∗00​⋯⋯⋯⋯​∗∗1​0​​1​∗​:pivot:any number​
Properties
  1. It has a staircase shape.
  2. Below the stairs, we have only zeros.
  3. Moving down the rows, the pivot moves to the right.
  4. Columns containing pivots are called pivot columns.

Dimension of Vector Spaces​

Leading Question

How do we quantify how big the solution set is?

Linear Independence​

Linear Independence

Recall from last time that a set of vectors B={v1,…,vk}B=\{\mathbf{v}_1,\dots,\mathbf{v}_k\}B={v1​,…,vk​} is linearly independent if:

c1v1+⋯+civi+⋯+ckvk=0  ⟹  ci=0 for all ic_1\mathbf{v}_1+\dots +c_i\mathbf{v}_i+\dots+c_k\mathbf{v}_k=0 \implies c_i=0 \text{ for all } ic1​v1​+⋯+ci​vi​+⋯+ck​vk​=0⟹ci​=0 for all i
Non-Example

{v1,v2,v3}\{ \mathbf{v}_1,\mathbf{v}_2,\mathbf{v}_3\}{v1​,v2​,v3​} is not linearly independent since:

v1+v3=v2\mathbf{v}_1+\mathbf{v}_3=\mathbf{v}_2v1​+v3​=v2​

System of Generators​

System of Generators

A set of vectors {v1,…,vk}⊂V\{\mathbf{v}_1,\dots,\mathbf{v}_k \}\subset V{v1​,…,vk​}⊂V is a System of Generators if any vector v\mathbf{v}v in VVV can be written as:

v=c1v1+⋯+ckvk\mathbf{v}=c_1\mathbf{v}_1+\dots + c_k\mathbf{v}_kv=c1​v1​+⋯+ck​vk​
Example

Any vector v∈Λ\mathbf{v}\in \Lambdav∈Λ can be written as:

v=c1v1+c2v2\mathbf{v}=c_1\mathbf{v}_1+c_2\mathbf{v}_2v=c1​v1​+c2​v2​

if and only if the set {v1,v2}\{\mathbf{v}_1, \mathbf{v}_2 \}{v1​,v2​} is a system of generators for the plane

Basis​

Basis

A set of vectors {v1,…,vk}⊂V\{\mathbf{v}_1,\dots , \mathbf{v}_k \} \subset V{v1​,…,vk​}⊂V is called a basis for VVV if it is both Linearly Independent and a System of Generators

Example

In the above example, {v1,v2}\{\mathbf{v}_1, \mathbf{v}_2\}{v1​,v2​} is a basis (check that they are linearly independent)

Fact on Cardinality

Given a vector space VVV, any two bases B1B_1B1​ and B2B_2B2​ have the same Cardinality (the number of elements)

Dimension​

Dimension

We can define the Dimension of a vector space VVV as the cardinality of a basis BBB for VVV, denoted as:

dim⁡(V)\operatorname{dim}{(V)}dim(V)

Image and Rank​

Matrix Associated to a Linear Map​

Matrix Associated to a Linear Map

Recall that the linear map φ:Rn→Rm\varphi:\mathbb{R}^n\rightarrow\mathbb{R}^mφ:Rn→Rm corresponds to its associated matrix:

φ:Rn→Rm⟺A=[a11⋯a1n⋮⋱⋮am1⋯amn]=(φ(e1),…,φ(en))\varphi:\mathbb{R}^n\rightarrow\mathbb{R}^m \qquad\Longleftrightarrow\qquad A= \begin{bmatrix} a_{11} & \cdots & a_{1n}\\ \vdots & \ddots & \vdots\\ a_{m1} & \cdots & a_{mn} \end{bmatrix} = \big( \varphi(\mathbf{e}_1), \dots, \varphi(\mathbf{e}_n) \big)φ:Rn→Rm⟺A=​a11​⋮am1​​⋯⋱⋯​a1n​⋮amn​​​=(φ(e1​),…,φ(en​))

Image​

Image of Linear Map

The Image of a linear map is a vector space, and the column vectors of its associated matrix form a system of generators for the image, denoted as:

Im⁡(φ)=span⁡{columns of A}\operatorname{Im}(\varphi)=\operatorname{span}\{\text{columns of }A\}Im(φ)=span{columns of A}
Derivation

Take v1,v2∈Im⁡(φ)\mathbf{v}_1,\mathbf{v}_2\in \operatorname{Im}(\varphi)v1​,v2​∈Im(φ)

  • Im⁡(φ)\operatorname{Im}(\varphi)Im(φ) is a vector space:

      ⟹  v1=φ(x1)v2=φ(x2)\implies \mathbf{v}_1=\varphi(\mathbf{x}_1)\qquad \mathbf{v}_2=\varphi(\mathbf{x}_2)⟹v1​=φ(x1​)v2​=φ(x2​)   ⟹  v1+v2=φ(x1)+φ(x2)=φ(x1+x2)∈Im⁡(φ)\implies \mathbf{v}_1+\mathbf{v}_2=\varphi(\mathbf{x}_1)+\varphi(\mathbf{x}_2)=\varphi(\mathbf{x}_1+\mathbf{x}_2)\in \operatorname{Im}(\varphi)⟹v1​+v2​=φ(x1​)+φ(x2​)=φ(x1​+x2​)∈Im(φ)

    Same for cvc\mathbf{v}cv:

    cv1=cφ(x1)=φ(cx1)∈Im⁡(φ)c\mathbf{v}_1=c\varphi(\mathbf{x}_1)=\varphi(c\mathbf{x}_1)\in \operatorname{Im}(\varphi)cv1​=cφ(x1​)=φ(cx1​)∈Im(φ)

  • Im⁡(φ)=span⁡{columns of A}\operatorname{Im}(\varphi)=\operatorname{span}\{\text{columns of }A\}Im(φ)=span{columns of A}

    x=x1e1+⋯+xnen  ⟹  φ(x)=x1φ(e1)+⋯+xnφ(en)\mathbf{x}=x_1\mathbf{e}_1+\dots+x_n\mathbf{e}_n\implies \varphi(\mathbf{x})=x_1\varphi(\mathbf{e}_1)+\dots+x_n\varphi(\mathbf{e}_n)x=x1​e1​+⋯+xn​en​⟹φ(x)=x1​φ(e1​)+⋯+xn​φ(en​)

    so any vector in the image can be written as a linear combination of the columns of AAA. Therefore:

Im⁡(φ)=span⁡{columns of A}■\operatorname{Im}(\varphi)=\operatorname{span}\{\text{columns of }A\} \tag*{$\blacksquare$}Im(φ)=span{columns of A}■

Rank​

Rank

The Dimension of an image dim⁡(Im⁡(φ))\operatorname{dim}\big(\operatorname{Im}(\varphi)\big)dim(Im(φ)) is equal to the maximum number of linearly independent columns. This is also called the Rank of φ\varphiφ, denoted as rank⁡(φ)\operatorname{rank}(\varphi)rank(φ), or the Rank of AAA, denoted as rank⁡(A)\operatorname{rank}(A)rank(A)

Final Remark​

Final Remark

A linear system Ax=bA\mathbf{x}=\mathbf{b}Ax=b (equivalently, φ(x)=b\varphi(\mathbf{x})=\mathbf{b}φ(x)=b) has a solution if and only if b∈Im⁡(φ)\mathbf{b}\in \operatorname{Im}(\varphi)b∈Im(φ).

Since Im⁡(φ)=span⁡{columns of A}\operatorname{Im}(\varphi)=\operatorname{span}\{\text{columns of }A\}Im(φ)=span{columns of A}, this means b\mathbf{b}b must be a linear combination of the columns of AAA — that is, adding b\mathbf{b}b as a new column to AAA should not increase the number of linearly independent columns. Hence:

Ax=b has a solution  ⟺  rank⁡([A∣b])=rank⁡(A)A\mathbf{x}=\mathbf{b} \text{ has a solution} \iff \operatorname{rank}([A\mid\mathbf{b}])=\operatorname{rank}(A)Ax=b has a solution⟺rank([A∣b])=rank(A)

If rank⁡([A∣b])>rank⁡(A)\operatorname{rank}([A\mid\mathbf{b}])>\operatorname{rank}(A)rank([A∣b])>rank(A), then b\mathbf{b}b is not in the span of the columns of AAA, so the system has no solution.
