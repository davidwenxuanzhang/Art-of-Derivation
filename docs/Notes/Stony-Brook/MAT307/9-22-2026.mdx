## Recap

Our main motivation is to solve the linear systems $A\mathbf{x}=0$ or $A\mathbf{x}=\mathbf{b}$ and describe the solution set.

Giving a matrix $A_{m\times n}$ is the same as giving a linear map:

$$
\begin{align*}
    \varphi_{A}:\ &\mathbb{R}^n\rightarrow \mathbb{R}^m\\
                &\mathbf{x}\mapsto A\mathbf{x}
\end{align*}
$$

:::danger Important Notion

[Dimension](docs/Notes/Stony-Brook/MAT307/9-17-2026.mdx#Dimension) of a vector space $V$ is the cardinality of the [basis](docs/Notes/Stony-Brook/MAT307/9-17-2026.mdx#Basis) of $V$.

:::

## Coordinates and Basis
### Unique Representation in a Basis

:::tip Corollary

Let $B\subseteq V$ be a basis, then every vector $\mathbf{v}\in V$ can be written uniquely as:

$$
\mathbf{v}=c_1\mathbf{v}_1+\dots +c_k\mathbf{v}_k
$$

<details>
<summary><span className="math-keyword">Derivation</span></summary>

We already know that $B$ is a system of generators, so we can write any $\mathbf{v}=c_1\mathbf{v}_1+\dots+c_k\mathbf{v}_k$. Thus, we only need to prove that the $c_i$s are uniquely determined.

Suppose we can also write $\mathbf{v}=c_1^{\prime}\mathbf{v}_1+\dots +c_k^{\prime}\mathbf{v}_k$, and our goal is to show $c_i^{\prime}=c_i$ for any $i$. Then:

$$
\begin{align*}
    c_1\mathbf{v}_1+\dots +c_k\mathbf{v}_k &= \mathbf{v} = c_1^{\prime}\mathbf{v}_1+\dots +c_k^{\prime}\mathbf{v}_k\\
    \implies (c_1-c^{\prime}_1)\mathbf{v}_1+\dots +(c_k-c^{\prime}_k)\mathbf{v}_k&= \mathbf{0}
\end{align*}
$$

As $B$ is linearly independent, then:

$$
c_i-c^{\prime}_i=0\implies c_i=c^{\prime}_i \quad\text{for all } i \tag*{$\blacksquare$}
$$

</details>

:::

### Rank Nullity Relation

:::tip Rank Nullity Relation

More generally, if $A$ has $\operatorname{Rank}(A)$, the dimension of the solution set of $A\mathbf{x}=\mathbf{0}$ is $n-\operatorname{Rank}(A)$, where $n$ is number of variables, which is the number of columns.

More specifically, the solution set of $A\mathbf{x}=\mathbf{0}$ is also called the **Kernel** of $A$, and we have:

$$
\dim\ker (A)=n-\operatorname{rank}(A)
$$

<details>
<summary><span className="math-keyword">Derivation</span></summary>

We just gave a recipe to write a basis of the solution set.

</details>

:::

## Nonhomogeneous Linear Systems

The form $A\mathbf{x}=\mathbf{0}$ is a nonhomogeneous linear systems, but what about the general case $A\mathbf{x}=\mathbf{b}$?

### General Solution

:::tip General Solution

The general structure of the solution set $S$ is a translation of a vector space, that is:

$$
S=\{x_0+\mathbf{v} \text{ where } \mathbf{v} \in S_0\}
$$
where x_0 is a special solution, and $S_0$ is the solution set of $A\mathbf{x}=\mathbf{0}$

<details>
<summary><span className="math-keyword">Derivation</span></summary>

Let $\mathbf{x}_0\in S$, in which $\mathbf{x}_0$ is any solution of the linear system, if there is one, then $A\mathbf{x}_0=\mathbf{b}$

- Now, let us verity that for any $\mathbf{v}\in S_0=\{\mathbf{v}\in \mathbb{R}^n \text{ such that } A\mathbf{v}=\mathbf{0} \}$, we have $A(\mathbf{x_0}+\mathbf{v})=\mathbf{b} $, indeed that:

$$
A(\mathbf{x}_0+\mathbf{v})=\mathbf{b}=A\mathbf{x}_0+A\mathbf{v}=\mathbf{b}+\mathbf{0}=\mathbf{b}
$$

- We have to check also that any $\mathbf{y}\in S$ can be written as $\mathbf{y}=\mathbf{x}_0+\mathbf{v}$ for some $\mathbf{v}\in S_0$ 

$$
A\mathbf{v}=A(\mathbf{y}-\mathbf{x}_0)=A\mathbf{y}-A\mathbf{x}_0=\mathbf{b}-\mathbf{b}=\mathbf{0}
$$

</details>


:::

### Existence of Solution

:::tip Existence of Solution
How can I decide if there is a solution?

I just have to do Gaussian Elimination for the matrix $(A\mid \mathbf{b})$

- If $\operatorname{rank}(A\mid \mathbf{b})=\operatorname{rank}(A) $, then there is a solution

- If $\operatorname{rank}(A\mid \mathbf{b})>\operatorname{rank}(A) $, then there are no solution

:::
