Functions of Several Variables​

Functions of Several Variables

Functions of several variables is:

f:Rn→Rf: \mathbb{R}^n\rightarrow \mathbb{R}f:Rn→R

More generally, the domain DDD could just be a subset of R\mathbb{R}R as:

f:D→R,D⊆Rnf:D\rightarrow \mathbb{R}, \qquad D\subseteq \mathbb{R}^nf:D→R,D⊆Rn

Graph of a Function​

Graph is a really convinient way to think of a function of several variables, here we will do a example:

Paraboloid​

Example (Paraboloid)

Consider the function:

f(x,y)=x2+y2f(x,y)=x^2+y^2f(x,y)=x2+y2

this is a case where n=2n=2n=2, and we can try to graph it:

graph⁡(f)={(x,y,z)∈R3 such that z=f(x,y)}\operatorname{graph}(f)= \{(x,y,z)\in \mathbb{R}^3 \text{ such that } z= f(x,y) \}graph(f)={(x,y,z)∈R3 such that z=f(x,y)}

In this case, we get a so-called Paraboloid

Vertical Slice​

But, given a graph, how can we determine whether or not it is a paraboloid? Vertical Slice is a good method.

Vertical Slice

I can slice the graph with vertical plane that contains zzz-axis and the normal direction is on the x,yx,yx,y plane; then, let the normal vector be a,b,0a,b,0a,b,0, the plane could be written as:

ax+by=0{y=−abxif b≠0x=−bayif a≠0ax+by=0 \begin{cases} y=-\frac{a}{b}x\qquad \text{if }b\ne 0\\ x=-\frac{b}{a}y\qquad \text{if }a\ne 0 \end{cases}ax+by=0{y=−ba​xif b=0x=−ab​yif a=0​

then, the equation of the function on such plane looks like:

f(x,y)=x2+(−bax)2=x2+b2a2x2=(1+b2a2)x2= a parabola\begin{align*} f(x,y)&=x^2+\left(-\frac{b}{a}x\right)^2\\ &=x^2+\frac{b^2}{a^2}x^2\\ &=\left(1+\frac{b^2}{a^2}\right)x^2\\ &= \text{ a parabola} \end{align*}f(x,y)​=x2+(−ab​x)2=x2+a2b2​x2=(1+a2b2​)x2= a parabola​

Saddle​

Example (Saddle)

Given a function:

f(x,y)=x2−y2f(x,y)=x^2-y^2f(x,y)=x2−y2

let us try some vertical slices:

v=(1,0,0)\mathbf{v}=(1,0,0)v=(1,0,0)

v=(0,1,0)\mathbf{v}=(0,1,0)v=(0,1,0)

Remark

When you go in higher dimensions such as n≥3n\ge 3n≥3, you cannot know the graph, but you can always draw vertical 2-dimension or 3-dimension slices of the graph.

Level Sets​

Level Sets

Given a function:

f:Rn→Rf:\mathbb{R}^n\rightarrow \mathbb{R}f:Rn→R

a level set for fff is:

ℓk={x∈Rn such that f(x)=k}\ell_{k}=\{ \mathbf{x}\in \mathbb{R}^n \text{ such that } f(\mathbf{x})=k \}ℓk​={x∈Rn such that f(x)=k}
Example

Back to the example paraboloid,

f(x,y)=x2+y2f(x,y)=x^2+y^2f(x,y)=x2+y2ℓk={x∈R2 such that x2+y2=k}\ell_{k}=\{ \mathbf{x}\in \mathbb{R}^2 \text{ such that } x^2+y^2=k \}ℓk​={x∈R2 such that x2+y2=k}

Continuity and Differentiation of Functions of Several Variables​

Continuity​

Continuity

Our working hypothesis will be that fff is continuous, that is:

lim⁡x→x0f(x)=f(x0) for any x0 in the domain\lim_{\mathbf{x}\rightarrow \mathbf{x}_0}f(\mathbf{x})=f(\mathbf{x}_0) \text{ for any }\mathbf{x}_0 \text{ in the domain}x→x0​lim​f(x)=f(x0​) for any x0​ in the domain
note

In more precise math terms it means that for any ε>0\varepsilon >0ε>0 there exists a small ball BBB around x0\mathbf{x}_0x0​ in the domain such that

f(B)⊆(f(x0)−ε, f(x0)+ε)f(B)\subseteq \big(f(\mathbf{x}_0)-\varepsilon,\, f(\mathbf{x}_0)+\varepsilon\big)f(B)⊆(f(x0​)−ε,f(x0​)+ε)

Given a function f:Rn→Rf:\mathbb{R}^n\rightarrow \mathbb{R}f:Rn→R, the partial derivative is defined as:

∂xif(v)=lim⁡ε→0f(v+εei)−f(v)ε\partial_{x_i}f(\mathbf{v})=\lim_{\varepsilon\rightarrow 0}\frac{f(\mathbf{v}+\varepsilon \mathbf{e}_i)-f(\mathbf{v})}{\varepsilon}∂xi​​f(v)=ε→0lim​εf(v+εei​)−f(v)​
Working Hypothesis

These partial derivatives exist and are continuous, which means they are not part of the definition, but are assumptions we make for later discussion.

Gradient​

Gradient

The Gradient of fff, denoted by ∇f\nabla f∇f, is the vector of partial derivatives

∇f(x)=(∂x1f(x),∂x2f(x),…,∂xnf(x))\nabla f(\mathbf{x})=\big(\partial_{x_1}f(\mathbf{x}),\partial_{x_2}f(\mathbf{x}),\dots,\partial_{x_n}f(\mathbf{x})\big)∇f(x)=(∂x1​​f(x),∂x2​​f(x),…,∂xn​​f(x))
Example
f(x,y)=x2−5y2f(x,y)=x^2-5y^2f(x,y)=x2−5y2∇f(x,y)=(2x,−10y)\nabla f(x,y)=(2x,-10y)∇f(x,y)=(2x,−10y)
Chain Rule
ddtf(γ(t))=∇f(γ(t))⋅γ′(t)where γ is a curve γ:R→Rn\frac{\mathrm{d}}{\mathrm{d}t}f\big(\gamma(t)\big)=\nabla f\big(\gamma(t) \big)\cdot \gamma^{\prime}(t)\quad \text{where } \gamma \text{ is a curve } \gamma :\mathbb{R}\rightarrow \mathbb{R}^ndtd​f(γ(t))=∇f(γ(t))⋅γ′(t)where γ is a curve γ:R→Rn
info

Geometric Interpretation

The gradient gives the direction of maximum increment of fff.

Proposition

The gradient is always orthogonal to the level sets of the function.

Derivation

Let's say that γ(t)\gamma(t)γ(t) is a level curve for fff, then:

f(γ(t))=k←(a constant)f\big(\gamma(t) \big)=k \leftarrow \text{(a constant)}f(γ(t))=k←(a constant)ddtf(γ(t))=∇f(γ(t))⋅γ′(t)=0\frac{\mathrm{d}}{\mathrm{d}t}f\big(\gamma(t) \big)=\nabla f\big(\gamma(t) \big)\cdot \gamma^{\prime}(t)=0dtd​f(γ(t))=∇f(γ(t))⋅γ′(t)=0  ⟹  ∇f(γ(t))⊥γ′(t)■\implies \nabla f\big(\gamma(t) \big) \perp \gamma^{\prime}(t) \tag*{$\blacksquare$}⟹∇f(γ(t))⊥γ′(t)■
