## Hypothesis Test

:::tip Hypothesis Test

A hypothesis test compares observed data with a model.
- We have data
- We have a model for what could have been seen in the data:

    In the guessing game example, where we count the number of correct guesses among people guessing on 10 T/F questions,
    $$
    \mathbb{X}\sim \mathcal{N}\left(\mu,\frac{\sigma^2}{N}\right), \mu=5, \sigma^2=\frac{5}{2}
    $$
- We make a hypothesis about the data ($\mu=5$)
- Test: Are the data consistent with the hypothesis/model? 

:::

### Articulate Hypothesis


::::tip Articulate Hypothesis

- A hypothesis specifies a population parameter and/or other unknown/observable quantities
    - The specification can be known, hypothetical, or counterfactual
    - Write the parameter $\theta$ and the specified value as $\theta_0$
    - The hypothesis states a relation between $\theta$ and $\theta_0$
        1. $\theta=\theta_0$. This is called a two-sided hypothesis
        2. $\theta<\theta_0 $ or $\theta>\theta_0 $. This is called a one-sided hypothesis
    - $\theta$ is often the population mean $\mu$ or the population variance $\sigma^2$
- A hypothesis generates a model $M(\theta_0)$ to describe uncertainty
    - The value $\theta_0$ is needed, as is other context.
    :::info Example
    Let $\theta$ be the population mean; from the guessing game example, $\theta_0=5$. $M(\theta_0)$ needs to describe uncertainty in the sample mean:

    $$
    \mathbb{X}\sim \mathcal{N}\left(\mu,\frac{\sigma^2}{N}\right)\quad \text{or}\quad \mathbb{X}\sim\mathcal{T}\left(5,\frac{s^2}{N},N-1 \right)
    $$

    :::
- The model has a distribution, which is the common link with the data
::::

- Model: CLT $\mathbb{X}\sim \mathcal{N}\left(\mu_0,\frac{\sigma^2}{N}\right)$
- Observation: $\bar{x}$

$$
\mathbb{P}(a\le \mathbb{X}\le b\mid C)\quad\text{and}\quad \bar{x}\in [a,b]
$$
