## Data Visualization

Data Visualization is a form of Qualitative Reduction, and there is rarely one correct answer to a problem.

Every effective Data Visualization has a **Message**, and there are ways to deliver that message more clearly, such as:
- Add a title
- Add annotations
- Choose an intuitive graph type


:::tip Characteristics of a Good Data Visualization
<div style={{ width: 'fit-content', margin: '0 auto' }}>

| Characteristics | Description |
|:---|:---|
| Clear | The message is easy to grasp at a glance, with no clutter or ambiguity |
| Concise | Shows only what is needed to carry the message, with no extra decoration or data |
| Concrete | Uses specific values, units, and real quantities rather than vague or abstract shapes |
| Contextual | Supplies what is needed to interpret it, such as labels, scale, units, reference points, and the data source |
| Correct | Represents the data accurately and without distortion (honest axes, proportions, comparisons) |
</div>

:::
