Hypothesis Tests​

Rough idea of Hypothesis Tests

  • Hypothesis: θ=θ0\theta=\theta_0θ=θ0​; we also call this M(θ0)\mathbb{M}(\theta_0)M(θ0​)

  • Observed data: mmm

  • Target: P[a≤M(θ0)≤b∣C],m∈[a,b]\mathbb{P}[a\le \mathbb{M}(\theta_0)\le b \mid C ],\quad m\in [a,b]P[a≤M(θ0​)≤b∣C],m∈[a,b] In this situation, [a,b][a,b][a,b] is called the acceptance region: we accept the hypothesis if our observed data land in this interval.

    • This is the definition of a test
    • If m∈[a,b]m\in [a,b]m∈[a,b], we accept the hypothesis θ=θ0\theta=\theta_0θ=θ0​
    • If m∉[a,b]m\notin [a,b]m∈/[a,b], we reject the hypothesis:
    (−∞,a)∪(b,∞) is the rejection region(-\infty ,a)\cup (b,\infty)\text{ is the rejection region}(−∞,a)∪(b,∞) is the rejection region

Below is a better definition.

Hypothesis Tests

A Hypothesis Test is a rule that tells us whether to accept or reject the hypothesis

  • It will involve a test statistic, also known as the summary statistic of the data.
  • M(θ0)\mathbb{M}(\theta_0)M(θ0​) is a model for uncertainty in the test statistic.
Example

Back to our guessing game example where the class of people randomly guess 10 T/F questions and count the number of correct guesses.

  • Test statistic: sample mean m=Xm=\mathbb{X}m=X
  • Hypothesis: μ=5,σ2=52,N=100→M(θ0)→X∼N(μ0,σ2N)=N(5,0.025)\mu=5,\sigma^2=\frac{5}{2}, N=100\rightarrow \mathbb{M}(\theta_0)\rightarrow \mathbb{X}\sim \mathcal{N}\left(\mu_0,\frac{\sigma^2}{N}\right)=\mathcal{N}(5,0.025)μ=5,σ2=25​,N=100→M(θ0​)→X∼N(μ0​,Nσ2​)=N(5,0.025)
  • Our test has the acceptance region [4.6,5.2][4.6,5.2][4.6,5.2]

Error​

Error

Error occurs when the test gives the wrong result, and there are two types of error:

  1. Accept the hypothesis when it is false (false positive)
  2. Reject the hypothesis when it is true (false negative)

Quantifying Error​

Quantifying Error
  • False Negative:
ε−=P[reject θ=θ0∣θ=θ0 is true]=1−P[accept θ=θ0∣θ=θ0 is true]=1−P[a≤M(θ0)≤b∣C]=1−F[b∣M(θ0)]+F[a∣M(θ0)]\begin{align*} \varepsilon_{-}&=\mathbb{P}[\text{reject }\theta=\theta_0\mid \theta=\theta_0\text{ is true} ]\\ &=1-\mathbb{P}[\text{accept }\theta=\theta_0\mid \theta=\theta_0\text{ is true} ]\\ &=1-\mathbb{P}[a\le \mathbb{M}(\theta_0)\le b\mid C]\\ &=1-F[b\mid \mathbb{M}(\theta_0)]+F[a\mid \mathbb{M}(\theta_0)] \end{align*}ε−​​=P[reject θ=θ0​∣θ=θ0​ is true]=1−P[accept θ=θ0​∣θ=θ0​ is true]=1−P[a≤M(θ0​)≤b∣C]=1−F[b∣M(θ0​)]+F[a∣M(θ0​)]​
  • False Positive:
ε+=P[accept θ=θ0∣θ=θ0 is false]=P[a≤M(θalt)≤b∣C]\begin{align*} \varepsilon_{+}&=\mathbb{P}[\text{accept }\theta=\theta_0\mid \theta=\theta_0\text{ is false} ]\\ &=\mathbb{P}[a\le \mathbb{M}(\theta_{\text{alt}})\le b\mid C] \end{align*}ε+​​=P[accept θ=θ0​∣θ=θ0​ is false]=P[a≤M(θalt​)≤b∣C]​

Notice that here we use θalt\theta_{\text{alt}}θalt​ instead of θ0\theta_0θ0​ because our hypothesis is false, which means we need an alternative model.

Example

Back to our guessing game where μ=5,N=100,σ2=52\mu=5, N=100, \sigma^2=\frac{5}{2}μ=5,N=100,σ2=25​

M(θ0)⟶X∼N(5,52100)=N(5,0.025)\mathbb{M}(\theta_0)\longrightarrow \mathbb{X}\sim \mathcal{N}\left(5,\frac{\frac{5}{2}}{100} \right)=\mathcal{N}(5,0.025)M(θ0​)⟶X∼N(5,10025​​)=N(5,0.025)
  • Test: Acceptance region as [4.75,5.25][4.75,5.25][4.75,5.25]
  • False negative rate: ϵ−=P(reject μ=5∣μ=5 is true)=1−P[4.75≤X≤5.25∣X∼N(5,0.025)]=0.114\begin{align*} \epsilon_{-}&=\mathbb{P}(\text{reject }\mu=5\mid \mu=5\text{ is true})\\ &= 1- \mathbb{P}[4.75\le \mathbb{X}\le 5.25\mid \mathbb{X}\sim \mathcal{N}(5,0.025)]\\ &=0.114 \end{align*}ϵ−​​=P(reject μ=5∣μ=5 is true)=1−P[4.75≤X≤5.25∣X∼N(5,0.025)]=0.114​
  • False positive rate: since μ=5\mu=5μ=5 is wrong, we use an alternative model ⟶X∼N(5.1,0.02)\longrightarrow \mathbb{X}\sim \mathcal{N}(5.1,0.02)⟶X∼N(5.1,0.02) ϵ+=P(accept μ=5∣μ=5 is wrong)=P[4.75≤X≤5.25∣X∼N(5.1,0.02)]=0.414\begin{align*} \epsilon_{+}&=\mathbb{P}(\text{accept }\mu=5\mid \mu=5\text{ is wrong})\\ &=\mathbb{P}[4.75\le \mathbb{X}\le 5.25\mid \mathbb{X}\sim \mathcal{N}(5.1,0.02)]\\ &=0.414 \end{align*}ϵ+​​=P(accept μ=5∣μ=5 is wrong)=P[4.75≤X≤5.25∣X∼N(5.1,0.02)]=0.414​
