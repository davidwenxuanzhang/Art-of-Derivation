Hypothesis Test​

Hypothesis Test

A hypothesis test compares observed data with a model.

  • We have data

  • We have a model for what could have been seen in the data:

    In the guessing game example, where we count the number of correct guesses among people guessing on 10 T/F questions,

    X∼N(μ,σ2N),μ=5,σ2=52\mathbb{X}\sim \mathcal{N}\left(\mu,\frac{\sigma^2}{N}\right), \mu=5, \sigma^2=\frac{5}{2}X∼N(μ,Nσ2​),μ=5,σ2=25​

  • We make a hypothesis about the data (μ=5\mu=5μ=5)

  • Test: Are the data consistent with the hypothesis/model?

Articulate Hypothesis​

Articulate Hypothesis

  • A hypothesis specifies a population parameter and/or other unknown/observable quantities

    • The specification can be known, hypothetical, or counterfactual
    • Write the parameter θ\thetaθ and the specified value as θ0\theta_0θ0​
    • The hypothesis states a relation between θ\thetaθ and θ0\theta_0θ0​
      1. θ=θ0\theta=\theta_0θ=θ0​. This is called a two-sided hypothesis
      2. θ<θ0\theta<\theta_0 θ<θ0​ or θ>θ0\theta>\theta_0 θ>θ0​. This is called a one-sided hypothesis
    • θ\thetaθ is often the population mean μ\muμ or the population variance σ2\sigma^2σ2

  • A hypothesis generates a model M(θ0)M(\theta_0)M(θ0​) to describe uncertainty

    • The value θ0\theta_0θ0​ is needed, as is other context.
    Example

    Let θ\thetaθ be the population mean; from the guessing game example, θ0=5\theta_0=5θ0​=5. M(θ0)M(\theta_0)M(θ0​) needs to describe uncertainty in the sample mean:

    X∼N(μ,σ2N)orX∼T(5,s2N,N−1)\mathbb{X}\sim \mathcal{N}\left(\mu,\frac{\sigma^2}{N}\right)\quad \text{or}\quad \mathbb{X}\sim\mathcal{T}\left(5,\frac{s^2}{N},N-1 \right)X∼N(μ,Nσ2​)orX∼T(5,Ns2​,N−1)

  • The model has a distribution, which is the common link with the data
