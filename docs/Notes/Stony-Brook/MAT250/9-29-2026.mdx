## Complement

Fix a set $U$ "universal", then:

::::tip Complement

For $A\subseteq U$. the **complement** of $A$, denoted by $A^{c}$ is defined by:

$$
A^{c}=U\setminus A=\{x\in U \mid x\notin A\}
$$

:::info Example
Let $U=\mathbb{Z}$, and $E$ is the set of all even integers, then:

$$
E^{c}=\mathbb{Z}-E=\{n\in \mathbb{Z}\mid n\notin E\}=\{n\in Z \mid 2 \nmid n\}=\text{ the set of odd integers}
$$

:::
:::danger Remark

The conclusion: "therefore, the complement of the set of all even integers is the set of all odd integers" is **WRONG** because it does not state the universal set $U$, which there is no matehmatical cause.
