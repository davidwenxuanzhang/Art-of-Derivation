Notation

For a positive integer nnn, we define Nn≔{1,2,…,n}\mathbb{N}_n\coloneqq \{1,2,\dots,n\}Nn​:={1,2,…,n}

Definitions

  • Cardinality:

    A non-empty set XXX has cardinality nnn if there exists a bijection

    f:Nn⟶Xf:\mathbb{N}_n\longrightarrow Xf:Nn​⟶X

    We then write the cardinality as ∣X∣≔n|X|\coloneqq n∣X∣:=n.

  • Finite Set

    A set is finite if it has cardinality nnn for some integer n≥0n\ge 0n≥0.

  • Infinite Set

    A set is said to be infinite if it is not finite.

    If there exists an injection f:Nm→Nnf:\mathbb{N}_m\rightarrow \mathbb{N}_nf:Nm​→Nn​, then m≤nm\le nm≤n

Uniqueness of Finite Cardinality​

Uniqueness of Finite Cardinality

Suppose

f:Nm⟶X and g:Nn⟶Xf:\mathbb{N}_m\longrightarrow X\quad \text{ and }\quad g:\mathbb{N}_n\longrightarrow Xf:Nm​⟶X and g:Nn​⟶X

is a bijection, then m=nm=nm=n.

Derivation

Since fff and ggg are bijections, their inverses exist, so the map:

g−1∘f:Nm⟶Nng^{-1}\circ f: \mathbb{N}_m\longrightarrow \mathbb{N}_ng−1∘f:Nm​⟶Nn​

is injective, so the Lemma gives m≤nm\le nm≤n. Similarly

f−1∘g:Nn⟶Nmf^{-1}\circ g: \mathbb{N}_n\longrightarrow \mathbb{N}_mf−1∘g:Nn​⟶Nm​

is injective, so by the Lemma, n≤mn\le mn≤m

Therefore, m=nm=nm=n.

Lemma

Let XXX and YYY be nonempty finite sets. If there exists an injection X→YX\rightarrow YX→Y, then ∣X∣≤∣Y∣|X|\le |Y|∣X∣≤∣Y∣

Derivation

We write ∣X∣=m|X|=m∣X∣=m and ∣Y∣=n|Y|=n∣Y∣=n, and choose bijection:

g:Nm⟶X,h:Nn⟶Yg:\mathbb{N}_m\longrightarrow X,\qquad h:\mathbb{N}_n\longrightarrow Yg:Nm​⟶X,h:Nn​⟶Y

Then,

h−1∘f∘g:Nm⟶Nnh^{-1}\circ f\circ g:\mathbb{N}_m\longrightarrow \mathbb{N}_nh−1∘f∘g:Nm​⟶Nn​

is injective, and by the Lemma, we get m≤nm\le nm≤n.

■\blacksquare■

If XXX and YYY are finite sets, then their Cartesian Product X×YX\times YX×Y is finite and ∣X×Y∣=∣X∣∣Y∣|X\times Y|=|X||Y|∣X×Y∣=∣X∣∣Y∣

Inclusion-Exclusion for Two Sets​

Inclusion-Exclusion for Two Sets

If XXX and YYY are finite sets, then

∣X∪Y∣=∣X∣+∣Y∣−∣X∩Y∣|X\cup Y|=|X|+|Y|-|X\cap Y|∣X∪Y∣=∣X∣+∣Y∣−∣X∩Y∣
Derivation

Recall from the Pairwise-Disjoint Decomposition:

X∪Y=(X∖Y)∪(Y∖X)∪(X∩Y)X\cup Y= (X\setminus Y)\cup (Y\setminus X)\cup (X\cap Y)X∪Y=(X∖Y)∪(Y∖X)∪(X∩Y)

Therefore, by the Addition Principle:

∣X∪Y∣=∣X∖Y∣+∣Y∖X∣+∣X∩Y∣|X\cup Y|= |X\setminus Y|+|Y\setminus X|+|X\cap Y|∣X∪Y∣=∣X∖Y∣+∣Y∖X∣+∣X∩Y∣

Also, because

X=(X∖Y)∪(X∩Y)X=(X\setminus Y)\cup (X\cap Y)X=(X∖Y)∪(X∩Y)

is a disjoint union, so

∣X∖Y∣=∣X∣−∣X∩Y∣|X\setminus Y|= |X|-|X\cap Y|∣X∖Y∣=∣X∣−∣X∩Y∣

Similarly, we can have:

∣Y∖X∣=∣Y∣−∣X∩Y∣|Y\setminus X|= |Y|-|X\cap Y|∣Y∖X∣=∣Y∣−∣X∩Y∣

Plug in those back:

∣X∪Y∣=(∣X∣−∣X∩Y∣)+(∣Y∣−∣X∩Y∣)+∣X∩Y∣=∣X∣+∣Y∣−∣X∩Y∣\begin{align*} |X\cup Y|&=\big( |X|-|X\cap Y|\big)+\big( |Y|-|X\cap Y|\big)+|X\cap Y|\\ &=|X|+|Y|-|X\cap Y| \tag*{$\blacksquare$} \end{align*}∣X∪Y∣​=(∣X∣−∣X∩Y∣)+(∣Y∣−∣X∩Y∣)+∣X∩Y∣=∣X∣+∣Y∣−∣X∩Y∣​■​

Finite Sets for the Real Numbers​

Maximum and Minimum Element

Let A⊆RA\subseteq \mathbb{R}A⊆R. An element b∈Ab\in Ab∈A is a minimum element of AAA, written b=min⁡Ab=\operatorname{min}Ab=minA, if b≤ab\le ab≤a for every a∈Aa\in Aa∈A

An element c∈Ac\in Ac∈A is a maximum element of AAA, written c=max⁡Ac=\operatorname{max}Ac=maxA, if c≥ac\ge ac≥a for every a∈Aa\in Aa∈A

Example

For

A={−1,17,12,−78,8}A=\{-1,17,12,-78,8 \}A={−1,17,12,−78,8}

we have:

min⁡A=−78andmax⁡A=17\operatorname{min}A=-78\quad \text{and}\quad \operatorname{max}A=17minA=−78andmaxA=17
Well-Ordering Principle

Every nonempty set of positive integers has a minimum element. This is the Well-Ordering Principle, which is equivalent to the Induction Principle.

Example

The set R>0\mathbb{R}_{>0}R>0​ has neither a minimum nor maximum element. Given a∈R>0a\in \mathbb{R}_{>0}a∈R>0​

a2∈R>0anda2<a\frac{a}{2}\in \mathbb{R}_{>0}\quad \text{and}\quad \frac{a}{2}<a2a​∈R>0​and2a​<a

so aaa cannot be a minimum. Similarly, 2a>a2a>a 2a>a, so aaa cannot be a maximum.

Theorem

Every nonempty finite subset of R\mathbb{R}R has a minimum and maximum element.
