:::tip 

Two sets $X$ and $Y$ have the same cardionality, written $|X|=|Y|$, if $X$ and $Y$ are equivalent, that is, exists a bijection $f:X\rightarrow Y$

$|X|\le |Y|$: exists a injection

$|X|<|Y|$: $|X|\le |Y|$ but $|X|\ne |Y|$, which means injective but not bijective.



:::

:::info Theorem

Suppose $X$ and $Y$ are non-empty set and $|X|>|Y|$, then every function $f:X\rightarrow Y$ is not injective

:::


:::tip Continuum Hypothesis

Every uncountable subset of a real number has same cardinality as $\mathbb{R}$

:::
