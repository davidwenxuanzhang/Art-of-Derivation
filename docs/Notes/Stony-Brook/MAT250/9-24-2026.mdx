## Quiz 1

## Set Theory

::::tip Set

Recall that a **Set** is a collectionof well-defined object.

:::info Example

- $A=\{1,3,5 \}={1,5,3}$
- $\mathbb{Q}=\{\frac{p}{q}, p,q\in \mathbb{Z}, q\ne 0 \}$
- $A=\{x\in S \mid P(x) \}$
- Let $A$ be a set of letters in "coffee" $A=\{\text{c},\text{o},\text{f},\text{e} \}$

:::

:::note 

The order of elements in  a set does not matter, but you cannot repeat the set element.

:::

::::

### Empty Set

::::tip Empty set 

The **Empty Set**, denoted by $\emptyset$ or $\varnothing$, is a set containing no element.

:::info Example

$$
c=\{n\in\mathbb{Z}\mid 1<n<2 \}= \emptyset
$$

:::

::::


### Equality of Sets

::::tip Equality of Sets

Two sets $A$ and $B$ are equal, written as $A=B$, if they have **precisely** same element, such that for a element $x$:

$$
x\in A\iff x\in B
$$

:::info Example

$$
A=\{-1,2 \},\ B=\{x\in \mathbb{R}\mid x^2-x-2=0 \}\implies A=B
$$

:::

:::danger Prove

To prove two sets $A$ and $B$ are equal, you must state:

$$
\begin{align*}
    \forall x\in A, \ x \in B  \\
    \forall y\in B, \ y \in A 
\end{align*}
$$
:::

::::

### Subset

::::tip Subset

A set $A$ is a **Subset** of a set $B$, denoted by $A\subseteq B$ or $B\supseteq A$, if every element of $A$ is an element of $B$


:::info Example

- $A\subseteq A$
- $\emptyset \subseteq A$

:::

::::


### Proper Subset

::::tip Proper Subset

If $A$ is a subset of $B$, and $\exists x\in B\text{ s.t. } x\notin A$, then $A$ is a **Proper Subset** of $B$, denoted by $A\subsetneq B$

:::info Example
Let $\mathbb{N}$ be the set of all natural number:
$$
{\mathbb{N}}\subsetneq \mathbb{Z}
$$

:::

::::

### Operation on Sets

:::tip Operation on Sets

Let $A$ and $B$ be two sets, then:
 
<hr/>

- **Intersection**:
    $$
    A\cap B = \{x\mid x\in A \land x\in B \}
    $$

<hr/>

- Union:
    $$
    A\cup B = \{x\mid x\in A \lor x\in B \}
    $$

<hr/>

- Disjoint 

    The set $A$ and $B$ are disjoint if:

    $$
    A\cap B=\emptyset
    $$
:::

### Set Difference

::::tip Set Difference

The difference of set $A$ and $B$, denoted by $A\setminus B$ or $A-B$:

$$
\begin{align*}
    A\setminus B=\{x\mid x\in A\land x\notin B \}\\
    B\setminus A=\{x\mid x\in B\land x\notin A \}
\end{align*}
$$

### Set Proposition

:::info Proposition

For any sets $A$ and $B$, the following three sets $A\cap B$, $A\setminus B$, and $B \setminus A$ are pariwise disjoint, and:
$$
(A\cap B)\cup (A\setminus B)\cup (B \setminus A)=A\cup B 
$$

### Power Set

::::tip Power Set

The **Power Set** of $x$, denoted by $\mathcal{P}(x)$, is the set of all subset of $x$, as:
$$
\mathcal{P}(x)=\{A\mid A\in x \}
$$

:::info Example

Let $x=\{ 1,2\}$, then the subset of $x$ is $\emptyset, \{1,2\},\{1\},\{2\}$, therefore:

$$
\mathcal{P}(x)=\big\{\empty, \{1,2\}, \{1\}, \{2\} \big\}
$$

:::

:::note 

$$
A\in \mathcal{P}(x)\iff A\subseteq x
$$

:::
