::::tip Random Variable

Let $\Omega$ be the sample space of our experiment. Random variable $X$ is a **Function** from sample space $\Omega$ to all real number $\mathbb{R}$.
:::note Alternative Expression
On the other word: for each outcome $\omega \in \Omega$, $X(\omega)$ is a real number.
:::
::::

## Discrete Random Variables

:::tip Discrete Random Variables

A random variable is **Discrete** when there is a countable set $\{x_1, x_2, \cdots\}$ such that $\sum_{i}P(X=x_i)=1$

:::

## Probability Mass Function {#PMF}

::::tip Probability Mass Function (PMF)

The **Probability Mass Function** (**PMF**) of a discrete random variable $X$ is the function $f_x$ defined as:

$$
p_X(x)\overset{\text{def}}{=}P(X=x)
$$
:::note Properties of PMF

In order for a function $f(x)$ to become a valid PMF, it has to satisfy these properties:
1. $f(x)\ge 0$ for any $x$
2. Exist value $x_1, x_2, \cdots $ such $\displaystyle \sum_{i}{f(x_i)}=1$

:::
::::

## Cumulative Distribution Function 

::::tip Cumulative Distribution Function (CDF)

The **Cumulative Distribution Function** (**CDF**) of a random variable $X$ with PMF $p$ is the function $F_x$ defined as:

$$
F_X{(x)}\overset{\text{def}}{=}P(X\leq x)=\sum_{x_i\leq x}f(x_i)
$$
:::note Properties of PMF

In order for a function to become a valid PMF, it has to satisfy these properties:
1. $F_X(x)$ is non decreasing
2. $\displaystyle\lim_{x\rightarrow - \infty}F_X(x)=0 $
3. $\displaystyle\lim_{x\rightarrow \infty}F_X(x)=1 $
:::
