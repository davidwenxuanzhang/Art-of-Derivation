##  Bernoulli Distribution

:::tip Bernoulli Distribution

If $X$ is a random variable with the PMF


$$
p_X(x) = 
\left\{\begin{aligned}
&p, &x=1\\
&1-p, &x=0
\end{aligned}
\right.
$$

for some $0\le x\le 1$, $X$ is said to be a **Bernoulli random variable with parameter $p$**, written as $X\sim \operatorname{Bernoulli}(p)$

:::
