Poisson Distribution​

Poisson Distribution

If XXX is a random variable with the PMF

pX(x)=e−μμxx!;x=0,1,2,…p_X(x)=e^{-\mu}\frac{\mu^x}{x!}; \qquad x=0,1,2,\dotspX​(x)=e−μx!μx​;x=0,1,2,…

for some μ>0\mu>0μ>0 then XXX is said to be a Poisson random variable with parameters μ\muμ, written as X∼Poisson⁡(μ)X\sim \operatorname{Poisson}(\mu)X∼Poisson(μ)

Example

The Poisson distribution models the number of times an event occurs in a fixed interval when events occur independently at a constant average rate.

Poisson Expectation and Variance

Let X∼Poisson⁡(μ)X\sim \operatorname{Poisson}(\mu) X∼Poisson(μ), then:

E[X]=μ\mathbb{E}[X]=\muE[X]=μ

and

Var⁡[X]=μ\operatorname{Var}[X]=\muVar[X]=μ
Derivation

Given a Negative Binomial random variable X∼Poisson⁡(μ)X\sim \operatorname{Poisson}(\mu) X∼Poisson(μ), we have the PMF:

pX(x)=e−μμxx!p_X(x)=e^{-\mu}\frac{\mu^x}{x!}pX​(x)=e−μx!μx​

Since calculating expectation and variance requires E[X]\mathbb{E}[X]E[X] and E[X2]\mathbb{E}[X^2]E[X2], we can directly Derive a general formula for the kkkth moment E[Xk]\mathbb{E}[X^k]E[Xk]

E[Xk]=∑x=0∞xke−μμxx!(LotUS)=∑x=1∞xke−μμxx!=μ∑x=1∞xk−1e−μμx−1(x−1)!\begin{align*} \mathbb{E}[X^k]&=\sum_{x=0}^{\infty}x^ke^{-\mu}\frac{\mu^x}{x!} &&(\text{LotUS})\\ &=\sum_{x=1}^{\infty}x^ke^{-\mu}\frac{\mu^x}{x!} \\ &=\mu \sum_{x=1}^{\infty}x^{k-1}e^{-\mu}\frac{\mu^{x-1}}{(x-1)!} \end{align*}E[Xk]​=x=0∑∞​xke−μx!μx​=x=1∑∞​xke−μx!μx​=μx=1∑∞​xk−1e−μ(x−1)!μx−1​​(LotUS)

Let i=x−1  ⟹  x=i+1i=x-1 \implies x=i+1i=x−1⟹x=i+1

  ⟹  E[Xk]=μ∑x=1∞(i+1)k−1e−μμii!⏟Y∼Poisson⁡(μ)=μE[(Y+1)k−1](Inverse LotUS)\begin{align*} \implies \mathbb{E}[X^k]&=\mu \sum_{x=1}^{\infty}{(i+1)}^{k-1}\underbrace{e^{-\mu}\frac{\mu^{i}}{i!}}_{Y\sim \operatorname{Poisson}(\mu)}\\ &=\mu\mathbb{E}[(Y+1)^{k-1}] &&(\text{Inverse LotUS}) \end{align*}⟹E[Xk]​=μx=1∑∞​(i+1)k−1Y∼Poisson(μ)e−μi!μi​​​=μE[(Y+1)k−1]​​(Inverse LotUS)​
